# NEXT 下一程 · 校园学习与成长工具平台

[![CI/CD](https://github.com/Ganzhib/next/actions/workflows/deploy.yml/badge.svg)](https://github.com/Ganzhib/next/actions/workflows/deploy.yml)

面向在校学生的独立产品发现与连接网站，覆盖校园学习、项目竞赛、科研升学与求职准备。当前正式接入方向为简历与 AI 面试，其他方向明确展示「敬请期待」。聚合平台管理介绍、分类、合集、推荐位和跳转，不在本站复制独立工具的业务功能。

## 本地启动

服务器部署、HTTPS、独立发布账号与 GitHub Actions 配置见 [部署文档](deploy/README.md)。

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173`。保持访问来源一致；`localhost` 与 `127.0.0.1` 的 IndexedDB 不共享。

```sh
npm run build
npm run preview
npm test
npm run test:e2e
```

端到端测试首次需要 `npx playwright install chromium`。测试使用独立浏览器上下文，不修改日常使用的数据。

## 技术与目录

- React + TypeScript + Vite。
- React Router 管理独立路由。
- Sass / SCSS：`src/styles/`，没有 Tailwind 依赖或工具类。
- Radix Dialog：键盘、焦点与弹窗基础交互。
- IndexedDB / idb：`src/storage/`。
- Zod 产品校验：`src/domain/models.ts`。
- 完整中文存储与迁移说明：`src/storage/README.md`。
- 页面：`src/pages/`。
- 通用组件：`src/components/`。

## 运营入口

访问 `/admin`，首次设置至少 6 位本地访问口令。口令仅用于本设备入口锁；本地数据可被开发者工具修改，不能用于公网多用户安全鉴权。刷新页面后重新解锁。

在「产品管理」编辑 Magic Resume 和 Interview Lab，填写真实独立产品地址，在「链接与归因」中点击「从网址提取允许域名」，保存后即可访问。当前未提供两个项目的真实 URL，因此没有虚构链接。

新增产品：后台 → 新增产品 → 填写基本信息和链接 → 设置发布状态 → 保存。前台、搜索和分类自动读取，无需修改路由和页面组件。

开发数据包含两个自有产品和 20 个明确标注的演示产品。前台默认隐藏演示数据；可以在「站点设置」开启，以测试搜索、筛选和分页。

## 已实现的本地能力

- 品牌首页、求职阶段、产品分类、全局命令搜索。
- 产品搜索、多条件筛选、排序、网格 / 列表、分页。
- 产品详情、优点局限、产品比较、分享链接。
- 合集详情、步骤、收藏。
- 编辑榜、最近更新、本地访问榜。
- 工作台、收藏、最近访问、偏好、明暗外观。
- 隐私同意、个人数据导出和删除。
- 产品提交、反馈、认领申请和本地审核。
- 本地运营入口锁、产品 CRUD、复制、归档、批量发布 / 隐藏。
- 产品 Logo 上传、分类管理、合集编排、推荐位配置。
- 首页模块排序 / 显隐 / 版本恢复、导航配置；同源标签页数据更新通知。
- 顶部默认只保留品牌、搜索、收藏；旧版导航入口保留在后台并关闭显示，不删除对应页面。已有浏览器通过一次性兼容升级同步，后台重新启用后不会被刷新覆盖。
- 真实本地事件图表、搜索记录、产品表现和事件调试。
- 访问地址格式和允许域名校验、无真实链接的明确状态。
- 站点设置、完整备份导出 / 恢复、审计日志、通知中心。

## 需要后续后端接入的能力

- 多设备用户账户、真实认证、SSO 与服务端 RBAC。
- 跨用户统计、DAU/MAU、留存及可信跨产品转化。
- DNS/TLS/HTTP 链接健康检查和后台定时任务。
- 服务端 302 跳转、Launch Token 签名、可信 Webhook。
- SSR/预渲染、动态 Sitemap、搜索引擎结构化数据。
- 支付、联盟佣金、邮件通知、产品方身份验证。

运营实验与商业合作目前支持保存配置记录；未伪装成已经接入分流或结算服务。数据库接口已经异步封装，后端选型后可以逐步替换适配器和对应服务。

定时发布仅在网站打开时检查到期产品，不是关闭浏览器后仍运行的服务。曝光后跳转率按“会话 + 产品”配对去重，只计曝光后发生的跳转，不等于第三方到达率或真实业务转化率。自有产品接入埋点 SDK 或可信回传后，才能统计产品内部使用行为。

## 设计

铅笔漫画、暖纸白留白、炭灰文字和鼠尾草绿胶囊按钮组成主视觉，插画以浅绿、雾蓝、奶杏等低饱和纸色承托，避免大面积纯黑白的生硬对比。原始插画不变，色彩融合通过 SCSS 实现；红色仅用于必要的警告语义。首页按「打磨简历 → 技术准备 → 练习面试 → 寻找机会 → 选择 Offer」展示五个原创漫画产品入口，阶段导航可以定位对应卡片。没有正式产品的阶段显示「敬请期待」，不创建虚假产品或访问链接。后台发布对应求职阶段的产品后会自动替换占位；同阶段优先展示首页推荐位中的产品，演示产品不填充真实阶段。响应式支持移动端、桌面端与深色模式。

漫画资源位于 `public/images/`，最终图片生成提示词与制作说明见 `public/images/ILLUSTRATIONS.md`。参考用户提供的漫画作品集截图提炼风格，未复制对方人物、作品或品牌素材。

## 注意

首页下半部分已用「校园探索」三组漫画图文替代重复的分类、求职合集和工具箱展示。原产品库、合集页面与数据均保留。新方向按 `campus-study`、`campus-projects`、`campus-research` 分类匹配已发布的非演示产品；没有产品时不显示虚假访问入口。后台「首页编排」支持校园模块的显隐与排序。

旧首页模块在读取时通过 `normalizeHomeModules` 兼容到新版，不直接清除旧配置。校园分类只做一次增量初始化，完成记录保存在 `records` 中；不会覆盖已有产品、个人数据或管理员设置。插画文件与最终提示词见 `public/images/CAMPUS-ILLUSTRATIONS.md`。

删除站点数据会删除 IndexedDB。请从后台定期导出完整备份。备份可能包含个人偏好、历史和本地访问口令摘要，请妥善保管。当前分析默认关闭，只有用户明确允许才记录本地事件。
